# Minimal Bilingual Resume

Static, responsive, single-page resume built with:

- HTML
- CSS
- Vanilla JavaScript
- JSON data
- GitHub Pages friendly

## Structure

- `index.html` — layout only
- `css/style.css` — design
- `js/app.js` — rendering, language and theme
- `data/resume.json` — resume content

Edit `data/resume.json` to change the resume.

For local development, use any static server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
